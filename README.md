# 朱入れ採点（Auto-grading for handwritten chemistry exams）

手書き答案のスキャンPDFを、AIが採点基準に沿って下採点し、先生が確認・修正して確定するための Web アプリです。高校化学の定期考査で実際に使うために作りました。

作者：岩野 芳樹

## 解決したい課題

定期考査の採点は、1クラス分でも数時間かかります。特に記述・計算・化学反応式の問題は部分点の判断が必要で、採点者によるばらつきも出やすい作業です。このアプリは、採点の「下書き」をAIに任せ、先生は確認と最終判断に集中できるようにすることを目指しています。

## 主な機能

1. **採点基準の自動作成**：問題と模範解答の小冊子PDFを読み込むと、AIが設問・配点・採点項目（マークスキーム）を下書きする。見開きページにも対応
2. **答案の一括採点**：1人1ファイル、または全員分が1つのPDFのどちらでも読み込める。氏名欄も読み取る
3. **5つの問題形式**：選択・穴埋め／数値／計算過程つき／記述・説明／化学式・反応式
4. **先生による確認**：AIの確信度が低い設問を「要確認」として表示。点数はその場で修正でき、記号の位置もクリックで直せる
5. **返却用PDFの作成**：答案には ◯・△・× だけを朱で書き込み、点数・設問別コメント・講評（よくできたところ、優先して取り組むこと、次の一歩）は別紙にまとめる
6. **採点一覧のCSV出力**

## 使っている技術

- HTML / CSS / JavaScript（1ファイル構成）
- [PDF.js](https://mozilla.github.io/pdf.js/)：PDFをページ画像に変換
- [jsPDF](https://github.com/parallax/jsPDF)：赤入れPDFの作成
- [JSZip](https://stuk.github.io/jszip/)：全員分のPDFをZIPにまとめる
- AI採点とデータ保存：claude.ai の Artifact 実行環境（`window.claude`）を利用

## 使い方

1. 「試験の設定」で問題・模範解答のPDFを読み込み、採点基準を確認して保存する
2. 「答案の採点」で答案PDFを読み込み、採点を実行する
3. 「確認と出力」で結果を確認・修正し、赤入れPDFとCSVを出力する

> 注意：AI採点と保存の機能は claude.ai 上の Artifact として開いたときだけ動きます。ブラウザで `index.html` を直接開いた場合、画面は表示されますがAI採点は使えません。

## プライバシー

- 答案画像はブラウザの中だけで扱い、保存しません。保存されるのは採点結果だけです
- 生徒の答案・氏名などの実データはこのリポジトリに含めていません
